📌 About

Hey there! 👋 I'm Nidhi Bandihole Prasanna, an aspiring data scientist and machine learning enthusiast with a love for math, logic, and building things from the ground up. 🚀

This web application is powered by a neural network model built entirely from scratch using just NumPy and pure math — no high-level libraries like TensorFlow or PyTorch were used. ✨ It's designed to recognize handwritten digits (0–9), just like the classic MNIST dataset challenges.

🧠 This project has been an exciting journey into understanding the fundamentals of how machines learn and recognize patterns. The current model consists of 3 layers and achieves an accuracy of 92.2% — not bad for a scratch-built neural net, right? 😄

🔧 I'm actively working on improving it by adding more layers, optimizing the learning process, and comparing its performance with industry-standard models. You can check out the full code, experiments, and results on my GitHub here: 🌐 GitHub Repository

✍️ Go ahead — draw a number in the box and click Predict to see what the model thinks you've written. It's a fun way to peek into how neural networks "see" your handwriting!

Thanks for visiting — and happy scribbling! 😊
